## Подтверждённые ошибки

### Невыполнимое требование в 4/7

Файл `TR/TR1/4/7.tex`, строки 5–10.

Требуется построить разбиение `A ∩ B` мощностью более 6, то есть хотя бы на 7 блоков. Между тем:

`A ∩ B = {6, 7, 8, 9, 84}`.

У этого множества 5 элементов. Блоки разбиения должны быть непустыми и попарно не пересекаться, поэтому их может быть не больше 5. Требование невыполнимо.

Для исправления нужно изменить либо данные, либо требуемое число блоков. Выбирать новый порог без решения автора не следует. Остальные варианты задания №4 выполнимы: разбиения на одноэлементные блоки уже удовлетворяют численным требованиям и имеют как минимум два общих блока.

### Отношение выходит за пределы множества в 9/3

Файл `TR/TR1/9/3.tex`, строки 3–5.

В множестве `A` перечислены целые числа от −2 до 11. Отношение `R₁`, объявленное на этом множестве, содержит `(12, −2)` и `(12, 2)`. Следовательно, `R₁` не является подмножеством `A × A`.

Возможные исправления — добавить 12 в `A` либо изменить пары. Из условия нельзя определить, какое исправление задумано.

### Не определено R₃ в 10/1–10/5

### Неправильная запись обратного отношения в 10/3

Файл `TR/TR1/10/3.tex`, строка 14:

```tex
R_1^3 \cap R_3^-1
```

В TeX после `^` без фигурных скобок в степень попадает только один следующий символ. Здесь в степени будет минус, а единица останется на основной строке. Для обратного отношения требуется:

```tex
R_1^3 \cap R_3^{-1}
```

### Невидимые скобки множеств в 1/8 и 1/9

Файлы `TR/TR1/1/8.tex` и `TR/TR1/1/9.tex`, строки 5–8.

Перечисления записаны в текстовом режиме как `{1, 3, 5, 7, 9}`. Обычные фигурные скобки в LaTeX группируют содержимое и не печатаются. Нужно экранировать скобки; для единообразной математической записи можно использовать:

```tex
\item $L = \{1, 3, 5, 7, 9\}$ (Лингвистика)
```

### Универсум для первой загадки 1/5

Файл `TR/TR1/1/5.tex`, строки 5–15.

Дополнение разрешено, но универсум не задан. Для первой загадки это существенно: используя только объединение, пересечение и разность, с указанным порядком `A ? B ? C ? D` и произвольными скобками получить `X` невозможно.

При `U = {1, 2, 3, 4, 5, 6}` подходит:

`X = Ā ∪ B̄ ∪ (C \ D) = {1, 2, 5, 6}`.

При `U = {1, 2, 3, 4, 5, 6, 7}` решения в том же порядке нет, даже если разрешить дополнение отдельных множеств и промежуточных выражений. Это проверено двумя способами: перебором достижимых множеств и независимым перебором всех 17 280 синтаксических выражений с объединением, пересечением, разностью и дополнениями в этом порядке.

Нужно явно задать универсум и уточнить, что дополнения разрешено ставить над множествами или выражениями. Например, можно задать `U = A ∪ B ∪ C ∪ D`. Вторая загадка 1/5 и обе загадки 1/6 имеют решения без дополнений.

### Контроль доказательных утверждений

- В 7/3 выражение `n³ + 3m² + 2m` делится на 6 тогда и только тогда, когда `n − m` делится на 6: разность выражений равна `(n³ − n) + 3m(m + 1)`, и оба слагаемых делятся на 6. Это отношение эквивалентности.
