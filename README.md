# Типовые расчёты по дискретной математике в университете ИТМО

Репозиторий содержит задания четырёх типовых расчётов первого курса и локальную веб-утилиту для редактирования LaTeX, предпросмотра и сборки PDF.

## Начать работу

1. Установите Git и Docker с Compose. Запустите Docker.
2. Для редактирования создайте собственный форк кнопкой **Fork** на GitHub. Для сборки принятых заданий используйте основной репозиторий.
3. Скопируйте URL выбранного репозитория кнопкой **Code**. Выполните команды, заменив `<URL_РЕПОЗИТОРИЯ>`:

	```sh
	git clone <URL_РЕПОЗИТОРИЯ> <НАЗВАНИЕ_РЕПОЗИТОРИЯ>
	cd <НАЗВАНИЕ_РЕПОЗИТОРИЯ>
	docker compose up --build
	```

4. После запуска сервера откройте **http://localhost:8080**.

Команда запуска одинакова на macOS, Windows и Linux. Python, Node и LaTeX вручную устанавливать не нужно. Первая сборка требует интернета. Для остановки нажмите `Ctrl+C` в терминале. Редактирование заданий не требует пересборки образа. Параметр `--build` нужен после изменения кода самой утилиты, её зависимостей или Dockerfile.
