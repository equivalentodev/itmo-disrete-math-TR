# Первая реализация утилиты

Дата: 21 октября 2026 года. Версия программы: 1.0.0.

## Реализовано

- Общее ядро Python 3.12 без сторонних runtime-зависимостей: чтение банков, CSV, сохранение назначений, распределение, формирование документов и ZIP.
- Русское меню из трёх действий: обзор всего типовика, именные работы по потокам, явное новое распределение.
- Для автоматических проверок доступны команды `review`, `students`, `redistribute` и `--root`. Основной пользовательский интерфейс остаётся меню.
- `TR/` — единственный банк. Общие шаблоны и настройки вынесены из `work/TR1`.
- Сохранение назначений по ИСУ ID в области учебного периода и типовика. Обычная сборка не перераспределяет прежних студентов; добавления и отсутствующие номера обрабатываются точечно.
- Новое распределение балансирует варианты отдельно по потокам, сохраняя уникальность полных комбинаций между выбранными потоками.
- Отбор CSV по потокам/группам, без прежнего ограничения на M3111. Выходные именные документы всегда по потокам.
- Версии ZIP и снимки назначений. Метаданные включают реквизиты, отбор, seed, контрольные суммы входов и архива. Прежние версии не перезаписываются.
- Проверки исходников, рисунков, состава документов и содержимого ZIP. Запись назначений атомарна; ошибка подготовки не заменяет прошлое состояние. Параллельная работа с одной `work/` блокируется.
- Docker и Compose; имя Compose-проекта задано явно, поэтому имя папки на кириллице не мешает запуску.
- Код входа контейнера сохраняет пользовательское владение выходными файлами на Linux, используя владельца подключённой `work/`.
- README, CONTRIBUTING, PR-шаблон, пустой шаблон и заполненный пример задачи. PDF-превью и Actions-компиляция не добавлялись.

## Docker и размер

Собраны образы для Linux arm64 и amd64. Измерения Docker 29:

| Архитектура | `docker image inspect .Size` | `docker image ls` |
|---|---:|---:|
| arm64 | 44 953 627 байт | 211 MB |
| amd64 | 45 299 740 байт | 185 MB |

Новый Docker с containerd показывает раздельные метрики содержимого и дискового использования; даже большее показанное значение укладывается в ограничение 512 МБ. Образ не содержит TeX Live, реальных списков студентов или файлов банков: они подключаются при запуске.

Проверена работа Linux-контейнеров на macOS. Отдельного запуска на настоящем Windows-хосте и Linux-хосте в этой сессии не было; переносимость обеспечивается Compose и отсутствием платформенных команд в пользовательском сценарии. На новом компьютере всё равно требуется установленный и запущенный Docker с Compose.

## Ограничения

- Программа не проверяет математическую истинность условий и внешний вид PDF.
- У ТР3 уже отсутствует указанный `pic/81.png`, у ТР4 — `pic/22.png` и `pic/433.png`. Сборка сообщает ошибку выбранного банка, не подставляет другие изображения и не создаёт неполный готовый ZIP. Эти условия не исправлялись.
- При новом распределении сначала используются до 256 детерминированных случайных попыток сбалансированных столбцов. Для плотного заполнения одним потоком строится дополнение к полному пространству; для небольших трудных случаев выполняется точный поиск (пространство до 256 комбинаций, до 250 000 узлов). Исчерпание поиска обозначается как неудача алгоритма, а не доказательство невозможности. Невалидное распределение не сохраняется.
- Прежняя выдача ТР1 импортирована как есть и не объявляется равномерной. Для перехода к новому алгоритму пользователь должен явно выбрать новое распределение.
- Если процесс был принудительно уничтожен, может остаться `work/.tool.lock`: прежде чем удалить его, нужно убедиться, что другой запуск не работает. При обычной ошибке, выходе или Ctrl+C блокировка снимается.
- GitHub-репозиторий не создавался и ничего не публиковалось. В этой папке пока нет `.git`; подготовлены локальные файлы и инструкция для последующего размещения в приватном репозитории.

```

```
