# Собрать типовик

Для выдачи студентам используйте принятые задания из `main` основного репозитория. Клонирование и запуск описаны в [README](../README.md#начать-работу).

## Подготовить выдачу

1. В клоне основного репозитория переключитесь на `main` и получите последние принятые изменения:

	```sh
	git switch main
	git pull --ff-only origin main
	```

2. В `config/project.toml` проверьте `course` и `term`: они определяют название курса и семестр в работе.
3. Для новой выдачи задайте новый `period`. Для пересборки прежней выдачи сохраните `period` и файлы в `work/assignments/`.
4. Откройте режим **Сборка**.
5. Выберите типовик.

## Собрать работы для студентов

1. Подготовьте CSV в UTF-8 с разделителем-запятой. Обязательные колонки: `ИСУ ID`, `ФИО`, `Поток`, `Группа`. У каждого студента должен быть уникальный `ИСУ ID`.
2. Загрузите CSV кнопкой **выберите файл** или перетащите в область загрузки. Можно положить файл в `work/students/` и выбрать в списке.
3. В разделе **Кого включить** выберите всех студентов, потоки или группы.
4. Сверьте число выбранных студентов и количества по потокам со списком.
5. Если назначения ещё не созданы, нажмите **Распределить варианты**. При пересборке с прежними назначениями пропустите этот шаг.
6. Оставьте включённым **Скомпилировать PDF**.
7. Нажмите **Собрать работы для студентов**.
8. Дождитесь сообщения **Готово. PDF собраны.**
9. Скачайте архив кнопкой **Скачать все PDF (ZIP)**. В архиве отдельный PDF для каждого потока.
10. Перед выдачей проверьте список студентов, ФИО и вёрстку PDF.

Кнопку **Распределить заново** используйте только для замены назначений. Обычная сборка сохраняет прежние номера вариантов.

Если нужны только исходники, перед сборкой снимите **Скомпилировать PDF**. Результат доступен по ссылке **Скачать исходники (ZIP)**.

## Собрать все варианты для проверки

1. Проверьте, что включён флажок **Скомпилировать PDF**.
2. В блоке **Проверка заданий** нажмите **Собрать типовик для проверки**. CSV и назначения для обзора не нужны.
3. Дождитесь завершения сборки.
4. Скачайте **PDF для проверки всех вариантов**. Файл `dump.pdf` содержит все задания по порядку и номера вариантов, без фамилий студентов.

## Найти результат или исправить ошибку

Готовые файлы остаются в `work/exports/<TRN>/<версия>/`. PDF находятся в `pdf/`, журналы в `logs/`. Рядом сохраняются ZIP, manifest и снимок назначений для именной сборки. Скачивание и перезапуск приложения эти файлы не удаляют.

Если сборка остановилась, откройте указанный исходник кнопкой **Открыть задание**. Для диагностики раскройте **Подробности и журнал компиляции**. После исправления повторите сборку. Подготовленные исходники и журнал ошибки находятся в `work/build/<TRN>/<версия>-failed/`.

Если программа сообщает об изменении исходников или CSV во время сборки, повторите операцию после сохранения файлов.

Для передачи работы следующему ответственному передайте папку `work/` отдельно от Git. В новом клоне нет списков студентов, прежних назначений и готовых выдач.
