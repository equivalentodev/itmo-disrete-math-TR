# Локальные данные и результаты

Содержимое этой папки, кроме README и пустого каркаса, не попадает в Git.

- `students/` — поместите сюда CSV с колонками `ИСУ ID`, `ФИО`, `Поток`, `Группа`.
- `assignments/` — сохранённые назначения по учебному периоду и типовику. Не удаляйте их, если хотите пересобирать прежние варианты.
- `build/` — предварительные исходники проектов. Не редактируйте здесь условия: они находятся только в `TR/`.
- `exports/` — готовые версии ZIP, снимки назначений и метаданные. В Overleaf загружайте только `.zip` из папки нужной версии.

При обычной сборке назначения сохраняются. Пункт «Создать новое распределение» явно заменяет назначения выбранных студентов; прежние версии остаются в `exports/`.

Для переноса работы другому ответственному передайте локальную папку `work/` отдельно от Git: в новом клоне списков студентов, назначений и прошлых выдач нет.

`build/legacy-TR1/` и версия `exports/TR1/TR1-legacy-…/`, если они есть, — сохранённые материалы прежней выдачи. Они не используются как актуальный банк заданий.
