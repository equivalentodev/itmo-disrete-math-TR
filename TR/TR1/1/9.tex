\question
В студенческом городке ИТМО проводят исследование посещаемости четырёх лабораторий:

\begin{itemize}
    \item L (Лингвистика): \{1, 3, 5, 7, 9\}
    \item C (Криптография): \{2, 4, 6, 8, 10\}
    \item A (Алгоритмы): \{1, 2, 3, 4, 5\}
    \item D (Дискретная математика): \{5, 6, 7, 8, 9\}
\end{itemize}

Для гранта необходимо выделить студентов, удовлетворяющих условию:
$$(L \cap  C) \cup (C \cap A) \setminus (A \cap D)$$
Найдите множество студентов, получивших грант. Перечислите элементы.
