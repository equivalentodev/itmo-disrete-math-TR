\question
Тест визового фильтра. Аня проверяет учебный сервис с условными правилами приёма заявки. Независимые флаги $a,b,c,d$ обозначают готовность анкеты, паспорта, фотографии и страховки соответственно; готовности соответствует $1$. Заявка принимается ровно тогда, когда полностью готова ровно одна из пар «анкета и паспорт», «фотография и страховка»; другая пара может быть готова частично либо не готова совсем.
\begin{enumerate}
\item Составьте СДНФ функции приёма $f(a,b,c,d)$.
\item Добавьте фиктивную переменную $e$, обозначающую включение тёмной темы интерфейса. Запишите СДНФ той же функции от пяти аргументов в порядке $a,b,c,d,e$.
\end{enumerate}
Наборы упорядочивайте лексикографически, начиная с нулевого. Все правила заданы только для этой задачи.
